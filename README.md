# 值日检查记录

给大队部老师单机使用的值日检查登记工具。纯静态网页，不需要服务器和登录，数据存在本机浏览器里，手机和电脑打开同一个链接即可使用，可以「添加到主屏幕」当 App 用，断网也能录入。

## 在线地址

| 校区 | 链接 | 年级 | 操场 |
| --- | --- | --- | --- |
| 东校区 | <https://huangxiangdong0923-sudo.github.io/duty-check-records/> | 一至四年级 | 金轮操场（一、四）、玉兔操场（二、三） |
| 南校区 | <https://huangxiangdong0923-sudo.github.io/duty-check-records/campus/south/> | 五、六年级 | 操场（五、六） |

两个校区是同一套代码、两份配置。页面按校区过滤记录：东校区只显示一至四年级，南校区只显示五、六年级。共用一块存储和一份云端数据，所以两边不会互相干扰，南校区老师把令牌也粘贴一次就能用同一份云端备份。

手机上打开链接后，用 Safari 的「分享 → 添加到主屏幕」或 Chrome 的「添加到主屏幕」，就能像 App 一样打开。

各设备的数据靠「云同步」打通（见下一节）。没开云同步时数据只存在当前这台设备上，换设备不会自动同步，可以用「历史与备份」里的 JSON 导出/导入来搬。

## 云同步（打开后手机和电脑共用同一份数据）

主屏幕上的 App 和浏览器里的网页是两块独立的本地存储，不开云同步的话两边数据不互通。云同步把记录存进一个私有 GitHub 仓库的 `records.json`：

| 项目 | 值 |
| --- | --- |
| 数据仓库 | <https://github.com/huangxiangdong0923-sudo/duty-check-data>（私有） |
| 同步文件 | `records.json` |
| 令牌 | GitHub fine-grained token，只授权这一个仓库的 Contents 读写 |

设置步骤：

1. 打开 <https://github.com/settings/personal-access-tokens/new>
2. Token name 填「值日检查同步」，Expiration 选 1 年
3. Repository access 选 **Only select repositories**，只勾 `duty-check-data`
4. Permissions → Repository permissions → **Contents** 设为 **Read and write**
5. Generate token，复制 `github_pat_` 开头的那串
6. 在 App 里进「历史与备份 → 云同步」，粘贴令牌，点「保存令牌并立即同步」

每个设备、每个入口（网页 / 主屏幕 App）只需粘一次，令牌存在本机浏览器里。

同步规则：

- 打开页面、切换回页面、保存或删除记录后都会自动同步
- 同一个 id 的记录以 `updatedAt` 较新的为准；删除用墓碑 id 记录，会同步到其它设备
- 上传前先拉取，抢写冲突会自动重试一次
- 顶部状态条显示「已同步 时间」，同步失败会显示原因，本机数据不受影响
- 令牌是 `api.github.com` 的 Bearer token，网页直接把记录读写到你自己的私有仓库，不经过第三方服务器

## 校区配置

各校区的年级、班级数、操场划分都在 `js/campuses.js`。改完后跑：

```sh
npm run build:campuses   # 重新生成 campus/<校区>/ 入口页与 manifest
npm test                 # 测试会校验生成结果是否和模板一致
```

要加第三个校区，在 `js/campuses.js` 里加一条配置，再跑一次上面两条命令即可。

## 两个模块

顶部切换，数据互不干扰。

### 日常值日检查

按日期、年级、班级登记日常扣分。位置可以填「第几排第几个」或学生姓名。

### 周一升旗检查

登记每周一升旗仪式的检查结果。

- 检查地点按年级自动判定：一、四年级在**金轮操场**，二、三年级在**玉兔操场**
- 扣分项固定 4 项，各扣 1 分：未佩戴红领巾、未穿着规范校服、未穿黑鞋子、升旗仪式迟到或逗留在班级
- 另有一项「其他情况」，需要手写备注
- **登记学号**：一次可以填多个，用空格或顿号分隔，例如 `3 7 12`
- 分值默认等于学号个数（3 个学号 = 3 分），可以手动改
- 学号留空表示整班问题，例如全班逗留在班级
- 日期默认落在最近一个周一

### 每周星级班级评比

「星级评比」页按**周一至周五**汇总本周的日常值日扣分和升旗检查扣分，给每个班打星。满分 250 分：

| 星级 | 本周扣分 | 得分 |
| --- | --- | --- |
| 五星班级 | 0 分 | 250 |
| 四星班级 | 1–2 分 | 248–249 |
| 三星班级 | 3 分及以上 | 247 及以下 |

页面上选任意一天即可跳到那一周，会显示「9月21日 周一 至 9月25日 周五」的统计范围。点「导出本周评比图片」生成一张 PNG，可以直接发群。

说明：

- 评比只看本校区自己的记录，校区之间互不影响
- 周六、周日的记录不计入评比
- 本周还没有检查记录的班级按「未被扣分」计为五星，页面底部会提示有多少个这样的班级

## 使用步骤

1. 打开链接，选「周一升旗检查」
2. 确认日期是本周一
3. 选年级、班级，界面会显示对应的操场
4. 在「学号」里填扣分的学号，多个用空格或顿号分开
5. 点中扣分项（红领巾 / 校服 / 黑鞋 / 迟到或逗留）
6. 点「保存记录」。同一个班还有别的问题，重复第 4–6 步

填错可以点记录右边的「删除」重录。

## 汇总与导出图片

切到「汇总」页，选日期：

- 按操场分成两段，只列有扣分的班级
- 同一个班里相同扣分项的学号合并成一行
- 点「导出当天图片」，生成一张 PNG，可以直接发到工作群
- 图片文件名：`2026-09-21-升旗检查扣分情况.png`

## 历史与备份

- 「历史与备份」页按日期回看以前每一次检查
- 「导出 JSON 备份」把全部数据存成一个文件，换手机时用「导入」恢复
- 合并导入只补新增的记录，覆盖导入会清掉本机现有数据
