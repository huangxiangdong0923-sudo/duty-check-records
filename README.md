# 值日检查记录

给大队部老师单机使用的值日检查登记工具。纯静态网页，不需要服务器和登录，数据存在本机浏览器里，手机和电脑打开同一个链接即可使用，可以「添加到主屏幕」当 App 用，断网也能录入。

## 在线地址

<https://huangxiangdong0923-sudo.github.io/duty-check-records/>

手机上打开链接后，用 Safari 的「分享 → 添加到主屏幕」或 Chrome 的「添加到主屏幕」，就能像 App 一样打开。

数据只存在当前这台设备上，换设备不会自动同步，用「历史与备份」里的 JSON 导出/导入来搬。

## 两个模块

顶部切换，数据互不干扰。

### 日常值日检查

按日期、年级、班级登记日常扣分。位置可以填「第几排第几个」或学生姓名。

### 周一升旗检查

登记每周一升旗仪式的检查结果。

- 检查地点按年级自动判定：一、四年级在**金轮操场**，二、三年级在**玉兔操场**
- 扣分项固定 4 项，各扣 1 分：未佩戴红领巾、未穿着规范校服、未穿黑鞋子、升旗仪式迟到或逗留在班级
- 另有一项「其他情况」，需要手写备注
- **登记学号**：一次可以填多个，用空格或顿号分隔，例如 `3 7 12`
- 分值默认等于学号个数（3 个学号 = 3 分），可以手动改
- 学号留空表示整班问题，例如全班逗留在班级
- 日期默认落在最近一个周一

## 使用步骤

1. 打开链接，选「周一升旗检查」
2. 确认日期是本周一
3. 选年级、班级，界面会显示对应的操场
4. 在「学号」里填扣分的学号，多个用空格或顿号分开
5. 点中扣分项（红领巾 / 校服 / 黑鞋 / 迟到或逗留）
6. 点「保存记录」。同一个班还有别的问题，重复第 4–6 步

填错可以点记录右边的「删除」重录。

## 汇总与导出图片

切到「汇总」页，选日期：

- 按操场分成两段，只列有扣分的班级
- 同一个班里相同扣分项的学号合并成一行
- 点「导出当天图片」，生成一张 PNG，可以直接发到工作群
- 图片文件名：`2026-09-21-升旗检查扣分情况.png`

## 历史与备份

- 「历史与备份」页按日期回看以前每一次检查
- 「导出 JSON 备份」把全部数据存成一个文件，换手机时用「导入」恢复
- 合并导入只补新增的记录，覆盖导入会清掉本机现有数据

## 本地运行

```sh
npm test                     # 单元测试
npm run serve                # 本地预览 http://localhost:5173
```

## 目录说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `app.js` | 界面状态与交互 |
| `styles.css` | 样式 |
| `js/modules.js` | 模块定义、升旗扣分项、操场归属 |
| `js/dates.js` | 日期工具（最近一个周一等） |
| `js/reasons.js` | 日常值日的扣分项 |
| `js/records.js` | 记录校验与规范化 |
| `js/storage.js` | 本机存储与备份 |
| `js/summary.js` | 汇总 |
| `js/image-export.js` | 图片排版与绘制 |
| `sw.js` / `manifest.webmanifest` | 离线缓存与主屏幕图标 |

## 部署
