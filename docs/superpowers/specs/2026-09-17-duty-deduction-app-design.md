# 值日扣分记录应用设计

## 1. 目标

为一名大队部教师提供一个手机和电脑都能打开的值日扣分记录工具。记录每天值日生检查发现的扣分情况，按班级汇总当天结果，并导出为 PNG 图片，便于发送和存档。

应用只服务单一使用者，不需要账号、多人协作或服务器端数据库。

## 2. 范围

### 交付内容

- 一个静态网页应用，兼容手机和电脑浏览器
- 可添加到手机主屏幕并按 PWA 方式离线打开
- 支持扣分登记、当天汇总、历史查看、PNG 导出和 JSON 备份
- 数据保存在当前设备的浏览器本地，通过备份文件在手机和电脑之间手动同步

### 不包含

- 登录、密码找回、多人权限
- 手机与电脑的自动实时同步
- 微信小程序、原生 App、App Store 或应用市场打包
- 云端数据库、消息推送、自动上报
- 图片或文字自动识别

## 3. 使用者与场景

- 使用者：一名大队部教师
- 主要场景：每天检查结束后，用手机录入扣分；也可以在电脑上查看、补充和导出
- 成功标准：录入一条记录不超过约 15 秒；当天记录能一键导出为一张完整、可读的扣分汇总图片

## 4. 运行方式与部署

- 技术形态：纯静态站点，HTML、CSS、JavaScript，无构建步骤
- 部署方式：部署到免费静态托管，首选 GitHub Pages；如果用户没有 GitHub 账号，则使用 Cloudflare Pages 或 Netlify
- 访问方式：手机和电脑打开同一网址；手机浏览器可添加到主屏幕
- 离线能力：首次打开后缓存应用外壳，断网仍可记录和导出
- 数据位置：浏览器本地存储，不上传服务器
- 同步方式：导出 JSON 备份到文件，在另一台设备导入并合并

## 5. 信息架构

应用包含三个主页面，用底部或顶部标签切换。

### 5.1 今日录入

默认首页。

输入项：

- 日期：默认今天，可修改
- 年级：一年级、二年级、三年级、四年级
- 班级：根据年级联动显示 1-18 班；四年级显示 1-23 班
- 位置方式：第几排第几个 / 学生姓名
- 第几排：正整数，按教室竖着数
- 第几个：正整数，按同一竖排从上往下数
- 学生姓名：位置方式选择“学生姓名”时显示
- 扣分时间：上午检查 / 下午检查 / 出操升旗 / 课间 / 眼保健操
- 扣分原因：固定选项按钮
- 分值：默认 1 分，允许临时改为 2 分或更多
- 备注：可选

操作：

- 保存后立即写入当天记录列表
- 当天记录按录入时间倒序显示
- 可编辑或删除单条记录
- 连续录入时保留日期、年级、班级等常用条件，减少重复操作

### 5.2 当天汇总

显示所选日期的扣分汇总。

- 按年级、班级分组
- 每个班显示本班扣分明细和合计
- 每条明细显示位置或学生姓名、扣分原因、分值
- 只显示有扣分的班级
- 底部显示当天总扣分数、涉及班级数、记录条数
- 提供“导出图片”按钮
- 没有记录时显示空状态，不生成空白图片

### 5.3 历史与备份

- 按日期列出已有记录的日期
- 点击日期查看当天明细并继续编辑
- 导出全部数据的 JSON 备份文件
- 导入另一台设备的 JSON 备份

导入策略：

- 默认使用“合并导入”
- 以记录 ID 去重，重复记录跳过
- 导入前显示本次将新增多少条、跳过多少条
- 提供“覆盖本机数据”作为高级选项，并要求二次确认

## 6. 固定扣分选项

扣分原因按现有《东校区学生值日细则》整理为按钮，默认扣 1 分。具体选项如下，文案可在开发前按原表再校一遍。

### 上午与下午教室检查

- 地面有比拳头大的垃圾、水杯或绳子
- 垃圾桶未套垃圾袋超过半桶，或套袋垃圾超过整桶
- 桌面乱涂乱画严重
- 柜子物品摆放不整齐
- 书包没有放在柜子里
- 地面有垃圾
- 劳动工具摆放不整齐
- 教室内风扇或电灯未关

### 出操与升旗

- 升旗仪式无故迟到
- 无故不出操
- 因身体不适留在教室却打闹

### 课间

- 爬栏杆、追逐打闹、大声喧哗或躺在地上打滚
- 在室外走廊和公共区域随意扔垃圾
- 损坏公物

### 眼保健操

- 提醒一次仍不做眼保健操
- 做眼保健操不认真

### 其他

- 顶撞、挑衅值日生
- 违反值日细则且已告知班长登记
- 其他情况，使用备注补充

“其他情况”记录时必须填写备注。

## 7. 数据模型

### 扣分记录

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 唯一标识，用于合并去重 |
| date | string | 日期，格式 YYYY-MM-DD |
| grade | number | 1、2、3、4 |
| classNo | number | 班级序号 |
| locationType | string | seat 或 student |
| row | number 或 null | 竖着数第几排 |
| seat | number 或 null | 同一竖排第几个 |
| studentName | string | 学生姓名，可为空 |
| slot | string | 检查时间段 |
| reasonCode | string | 固定原因代码 |
| reasonLabel | string | 固定原因显示文字 |
| points | number | 默认 1 |
| note | string | 备注，可为空 |
| createdAt | string | 创建时间，ISO 格式 |
| updatedAt | string | 最后修改时间，ISO 格式 |

### 本地存储

- 使用浏览器 localStorage 保存记录
- 存储键：`duty-deduction-records-v1`
- 记录量预计在 5000 条以内，localStorage 容量足够
- 每次写入前做一次结构校验；损坏数据不覆盖，提示用户恢复或导出

### 备份文件

```json
{
  "schemaVersion": 1,
  "exportedAt": "2026-09-17T10:00:00.000Z",
  "records": []
}
```

## 8. 图片导出设计

使用 Canvas 直接绘制，不依赖外部截图库。

- 画布宽度：1080 像素
- 高度：根据当天内容动态计算
- 背景：白色
- 标题：`M月D日值日检查扣分情况`
- 内容层级：年级 > 班级 > 明细
- 班级标题显示：`三年级1班（2分）`
- 明细格式：`第3排第4个 · 地面垃圾 · -1分`
- 学生姓名方式：`张三 · 桌面乱涂乱画 · -1分`
- 底部显示：当天合计、涉及班级数
- 没有扣分的班级不出现
- 导出文件名：`YYYY-MM-DD-值日检查扣分情况.png`

导出后优先触发浏览器下载；在手机 Safari 中如果无法直接下载，则显示长按保存提示。

## 9. 交互与错误处理

- 必填项未完成时，保存按钮不可用，并指出缺少的字段
- 排、个必须为正整数
- 选择“其他情况”但未填写备注时不允许保存
- 断网时仍可记录、汇总和导出，不显示网络错误
- 重复快速点击保存时只写入一条记录
- 删除记录前二次确认
- 导入无效备份文件时保持原数据不变
- 覆盖导入前必须二次确认
- 没有当天记录时不生成空白图片，并给出提示

## 10. 界面与视觉

- 中文界面，字体使用系统默认中文字体
- 手机优先，按钮尺寸适合单手操作
- 桌面端保持相同结构，内容区域居中，最大宽度受限，避免表格拉得过宽
- 主色沿用值日材料的蓝色，扣分数字使用红色
- 固定原因按钮采用网格排列，选中后有明显边框和底色
- 所有操作反馈使用文字提示，不只依赖颜色

## 11. 技术结构

文件结构：

```text
值日扣分记录/
├── index.html
├── styles.css
├── app.js
├── manifest.webmanifest
├── sw.js
├── icons/
└── docs/
```

模块划分：

- 存储模块：读写 localStorage、数据校验、备份导入导出
- 记录模块：新增、编辑、删除、按日期查询
- 汇总模块：按日期分组、按班级统计、合计计算
- 图片模块：Canvas 排版、换行处理、PNG 导出
- 界面模块：页面切换、表单校验、列表渲染
- PWA 模块：缓存应用外壳、支持添加到主屏幕

## 12. 测试

### 功能测试

- 一至四年级班级联动正确
- 四年级可选 1-23 班，其他年级只有 1-18 班
- 上午、下午、课间、出操和眼保健操原因正确保存
- 位置方式切换后只保存对应字段
- 默认扣 1 分，可临时修改
- 当天汇总按班级分组，零扣分班级不显示
- 修改和删除记录后汇总立即更新

### 数据测试

- JSON 导出后可正常导入
- 合并导入跳过重复 ID
- 损坏的备份文件不会覆盖现有数据
- localStorage 数据清空后可提示用户导入备份

### 图片测试

- 当天只有一条记录时可正常导出
- 多个班级、多条记录时图片高度自动扩展
- 长班级名称、长学生姓名和长原因不越出边距
- 手机和电脑导出的图片内容一致
- 图片中没有扣分的班级不出现

### 兼容性测试

- iPhone Safari 添加到主屏幕后打开正常
- Android Chrome 打开和导出正常
- 电脑 Chrome、Edge 和 Safari 打开正常
- 首次加载后断网仍可使用核心功能

## 13. 验收标准

- 手机和电脑打开网页即可使用
- 不登录、不上传数据即可记录
- 每条记录默认扣 1 分
- 当天汇总只显示有扣分的班级
- 一键导出当天汇总 PNG，图片排版完整无越界
- 可通过 JSON 备份在手机和电脑之间合并数据
- 应用可添加到手机主屏幕并离线打开
